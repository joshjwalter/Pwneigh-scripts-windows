# GPO selection and integration contract (unit G)

Default empty selection refuses configured GPO import. There is no recursive discovery or compatibility classifier. Populate `$DodGpoSelection` in exact desired import order, with one hashtable per direct child of `$DodGpoDir`:

```powershell
$DodGpoSelection = @(
    @{ Folder='operator-chosen-backup'; Package='actual package name'; Version='actual reviewed version'; Role='actual approved OS/role'; Approved=$true
       Files=@{ 'Backup.xml'='64 hexadecimal SHA256'; 'DomainSysvol/GPO/Machine/registry.pol'='64 hexadecimal SHA256' } }
)
```

Replace these illustrative values with operator-reviewed package metadata and **every** relative file and SHA256. Approval means the operator chose this package for the actual OS/role/version and its precedence. The script checks bytes, syntactic XML, regular files, bounds and selection; it cannot establish STIG compatibility or policy semantics. XML must not have DTDs; Backup.xml must have GroupPolicyBackupScheme root, with at least one nonempty Machine/User payload under DomainSysvol/GPO. This is a conservative minimum, not a complete LGPO schema validator. No actual package was provided or accepted in this review.

Bounds: 32 selections, 512 manifest files each, 1024 tree entries each, 16 path components, 240 relative path characters, 16 MiB per file and 64 MiB aggregate per folder. Reparse entries/ancestors are refused. All selections validate before backup/import, then the chosen folder validates again before each import. These checks cannot eliminate administrator/concurrent check/use races; protected accepted inputs and B executable revalidation remain required. Originals are never removed by G.

Integration assumptions (not implemented by this branch):

* F's Install-Tools runs before Install-DodGpo and registers canonical LGPO via B, including explicitly configured `$LgpoExe`. `State.Preconditions.NativeApprovals[canonicalPath]` has Role='LGPO', Digest, TrustPolicy (PinnedDigest/ValidSignature/ExpectedSigner), ResourceIdentity. Native errors throw; `Invoke-Step(Name,Action)` catches ordinary errors, records failure, returns one Boolean and rethrows cancellation. Foundation A still has the old step helper; it is not integrated safety proof.
* C must supply `Save-LocalPolicyRecoveryRecord(-LgpoPath)` returning exactly one ReadResult. G's shape checks do not independently prove these claims. C must refuse stale/unverifiable originals rather than adopt or overwrite them. This signature/schema requires reconciliation with C/B; no compatible implementation exists on common A. Firewall backup remains independent.

This signature requires reconciliation; G does not implement D observations or reinterpret Unknown as false.
